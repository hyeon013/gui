# 단위 변환기 및 하중 분석 GUI

다양한 단위를 변환하는 GUI와 CSV 하중 데이터를 분석하는 명령줄 및 Tkinter GUI 도구를 제공합니다.

## 주요 기능

- 🔄 **길이 변환** - 미터, 피트, 킬로미터, 마일 등
- ⚖️ **무게 변환** - 킬로그램, 파운드, 그램, 온스 등
- 🌡️ **온도 변환** - 섭씨, 화씨, 켈빈
- 💧 **부피 변환** - 리터, 밀리리터, 갤런 등
- 💨 **속도 변환** - m/s, km/h, mph 등
- ⚡ **실시간 변환** - 입력 즉시 결과 표시
- 📈 **CSV 하중 분석** - 단면적과 시간-응력 그래프 계산
- 🎨 **직관적인 인터페이스** - 누구나 쉽게 사용 가능

## 필수 요구사항

- Python 3.8 이상
- Tkinter (Python에 기본 포함)
- 하중 분석 그래프를 사용하려면 `matplotlib`

## 설치 방법

1. 저장소 복제
```bash
git clone https://github.com/hyeon013/gui.git
cd gui
```

2. 프로그램 실행
```bash
python main.py
```

## 사용 방법

1. 프로그램을 실행합니다.
2. 변환하고 싶은 카테고리를 선택합니다 (길이, 무게, 온도 등).
3. 변환할 값을 입력합니다.
4. 변환 전 단위와 변환 후 단위를 선택합니다.
5. 변환된 결과를 확인합니다.

## CSV 하중 분석기

`load_analyzer.py`는 CSV 하중 데이터의 검증과 분석 기능을 제공하며, `load_analyzer_gui.py`는 CSV 선택, 단면 치수 입력, 시간-응력 그래프를 갖춘 Tkinter 인터페이스입니다. 두 분석 방식 모두 입력 CSV를 수정하지 않습니다.

### 입력 데이터

CSV 첫 행에 다음 열 이름을 포함해야 합니다.

| 열 이름 | 의미 | 단위 |
| --- | --- | --- |
| `time_s` | 시간 | s |
| `force_N` | 하중 | N |

### 라이브러리 및 실행

CSV 처리는 Python 표준 라이브러리(`csv`, `math`, `pathlib`)를 사용합니다. 그래프에는 `matplotlib`이 필요합니다. 설치되지 않았다면 다음 명령으로 설치합니다.

```bash
python -m pip install matplotlib
```

프로젝트 폴더에서 다음 명령으로 분석기를 실행합니다.

```bash
python load_analyzer.py
```

명령줄 버전은 같은 폴더의 `load_data.csv`를 분석합니다. 단면적은 스크립트의 `AREA_MM2` 값(기본 100 mm²)을 사용합니다.

단면 형상과 크기를 지정하며 GUI에서 분석하려면 다음 명령을 실행합니다.

```bash
python load_analyzer_gui.py
```

GUI 상단의 **CSV 찾아보기** 버튼으로 CSV 파일을 선택하고, 단면 종류를 고르면 그 형상에 필요한 치수 입력칸만 표시됩니다. 치수를 입력하면 단면적이 자동으로 표시됩니다. **분석** 버튼을 누르면 유효 데이터 수, 최대 하중과 해당 시각, 최대 응력을 갱신하고 시간-응력 그래프를 그립니다. 그래프의 가로축은 `Time (s)`, 세로축은 `Stress (MPa)`이며, 응력은 `force_N / area_mm2`로 계산합니다. N/mm²는 MPa와 같습니다.

### 단면 종류 및 치수

모든 치수의 단위는 mm이며, 단면적은 mm²입니다.

| 단면 종류 | 입력 치수 | 면적 계산식 | 유효 치수 조건 |
| --- | --- | --- | --- |
| 사각형 | 폭 `b`, 높이 `h` | `A = b * h` | `b > 0`, `h > 0` |
| 원형봉(속이 참) | 지름 `d` | `A = π * d² / 4` | `d > 0` |
| 원형관(속이 빈) | 바깥지름 `D`, 두께 `t` | `d = D - 2t`, `A = π * (D² - d²) / 4` | `D > 0`, `0 < t < D/2` (내부 공간 유지) |
| 사각형관(속이 빈) | 바깥 폭 `B`, 바깥 높이 `H`, 두께 `t` | `A = B * H - (B - 2t) * (H - 2t)` | `B > 0`, `H > 0`, `t > 0`, `2t < min(B, H)` |
| H형강 | 플랜지 폭 `B`, 전체 높이 `H`, 웨브 두께 `tw`, 플랜지 두께 `tf` | `A = 2 * B * tf + (H - 2tf) * tw` | `B > tw > 0`, `H > 2tf`, `tf > 0` |

단면 치수는 빈칸, 숫자가 아닌 값, 0, 음수, 무한대 또는 형상상 유효하지 않은 값이면 분석을 시작하지 않고 안내합니다. 오류를 고친 뒤 프로그램을 다시 시작하지 않고 **분석**을 다시 누를 수 있습니다.

유효성 예시:

- 원형관 `D = 40`, `t = 2`: 안지름이 36 mm로 내부 공간이 남아 유효합니다. `t = 20`이면 내부 공간이 없어 분석을 중단합니다.
- 사각형관 `B = 40`, `H = 60`, `t = 25`: 내측 폭이 음수가 되므로 분석을 중단합니다.
- H형강 `H = 100`, `tf = 50`: 양쪽 플랜지 두께의 합이 전체 높이와 같으므로 분석을 중단합니다.

### 계산 설정 및 결과

- 명령줄 분석기의 단면적은 `load_analyzer.py`의 `AREA_MM2 = 100`에서 설정하고, GUI는 선택한 단면 형상과 치수로 계산합니다.
- 두 분석 방식 모두 최대 하중과 최대 응력을 계산합니다. 명령줄 버전은 6 MPa 기준을 초과하는 데이터 개수도 출력합니다.
- 명령줄 버전은 `time_s`, `force_N`, `stress_MPa` 열로 결과 CSV를 저장합니다. 기본 파일명은 `load_result.csv`이며, 같은 이름의 파일이 있으면 덮어쓰지 않고 `load_result_1.csv`, `load_result_2.csv`처럼 새 이름을 사용합니다.
- 명령줄 버전의 응력 그래프는 `stress_plot.png`로 저장합니다. GUI 그래프는 앱 창 하단에 표시됩니다.

### 오류 데이터 처리

- `time_s` 또는 `force_N`이 비어 있거나 유한한 숫자가 아니면 해당 원본 CSV 행 번호와 문제 값을 출력하고 그 행을 계산, CSV 결과 및 그래프에서 제외합니다. 제외 행 수와 유효 데이터 수를 함께 출력합니다.
- 필요한 열 이름(`time_s`, `force_N`)이 없으면 오류를 발생시킵니다.
- 유효한 데이터가 하나도 없으면 안내 메시지를 출력하고 결과 파일 저장을 중단합니다. GUI는 유효 데이터가 없음을 표시하며, 결과 그래프 대신 안내를 표시합니다.
- GUI에서 파일을 읽지 못하거나 단면 치수가 잘못되면 오류 대화상자를 표시합니다. 치수를 수정한 다음 다시 분석할 수 있습니다.
- 입력 CSV는 읽기만 하며 수정하지 않습니다.
